# Preprocessing

This folder contains the preprocessing scripts used to prepare continuous water temperature observations from the Yaquina Estuary for degree-hour modeling. Together, these scripts perform quality control, interpolate short gaps in the temperature record, aggregate observations to an hourly timestep, and export the final analysis-ready dataset.

The preprocessing workflow was developed to maximize data quality while preserving the integrity of the original observations. Original temperature measurements are retained whenever possible, with interpolated values used only to fill short gaps where appropriate.

---

## Workflow

```text
Raw HOBO Temperature Data
           │
           ▼
Find Duplicates
           │
           ▼
Monthly Range & Monthly Temp Diff
           │
           ▼
Temperature Quality Control
           │
           ▼
Harmonic Gap Filling
           │
           ▼
Export Analysis Dataset
           │
           ▼
Degree Hour Modeling
```

---

## Scripts

### Find Duplicates

- Identify and remove duplicate rows of data based on timestamp
- Export duplicate-filtered dataset

### Monthly Range & Monthly Temp Diff

Identify thresholds for QC tests 

- Calculate mean temperature by site for each year month (e.g. May 2023) for Climatology test
- Calculate mean temerature change between subsequent temperatures
- QC test based on threshold of 4 standard deviations
- Generate dataset of site-based thresholds for Temperature QC

### Temperature QC

Performs quality control on the raw 10-minute temperature observations.

Quality control includes:

- Neighborhood spike detection
- Rate-of-change detection
- Assignment of QC flags
- Documentation of removal reasons
- Creation of QC-filtered datasets while preserving original measurements

---

### Harmonic Interpolation

Fills short gaps in the QC-filtered temperature record using harmonic interpolation.

This script:

- Fits harmonic functions to surrounding observations
- Estimates missing temperatures for short gaps
- Preserves original observations
- Tracks which values were interpolated
- Produces a continuous temperature time series suitable for temporal analyses

---

Outputs include:

- Analysis-ready temperature dataset
- Summary tables for quality assurance

---

## Notes

These scripts are intended to be run sequentially, as each step depends on the outputs generated by the previous step.

The resulting datasets provide the foundation for all subsequent analyses within this repository, including degree-hour calculations, spatial interpolation, and visualization.
